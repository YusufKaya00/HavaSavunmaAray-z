## 2024-05-24 - LOH and GC Pressure in High-Frequency C# OpenCV processing
**Learning:** In C#, instantiating large `byte[]` arrays or `MemoryMappedViewAccessor` instances inside a `while(true)` loop running at high frequency (e.g., 60fps for video frames) causes severe Garbage Collection (GC) pressure and Large Object Heap (LOH) fragmentation. Since these frames are approx 1.2MB each, they bypass the Gen0 heap and go straight to LOH, causing frequent and expensive gen2/LOH collections which manifest as application stutter.
**Action:** Always pre-allocate and reuse large byte arrays and unmanaged accessors outside of high-frequency loops. This pattern transforms repeated large allocations into a single upfront allocation, stabilizing GC overhead to near zero for that code path.
